# Burst2Gif (무설치 브라우저 전용 연사 사진 GIF 변환기)

> **🔒 사진은 서버로 업로드되지 않습니다.**  
> 모든 이미지 디코딩, 리사이즈, 양자화, GIF 인코딩이 **100% 사용자의 웹 브라우저 내부에서만** 안전하게 처리됩니다.

별도의 프로그램(Python, FFmpeg 등) 설치나 회원가입 없이, 대용량 연사 사진(장당 20~50MB, 최대 1,000장)을 브라우저에 끌어다 놓아 고화질 GIF로 변환할 수 있는 순수 클라이언트 사이드 웹 애플리케이션입니다.

---

## 🌟 핵심 설계 원칙: Bounded-Memory Pipeline

고화질 연사 사진(예: 60MP, 9504×6336)은 압축이 풀리면 1장에 약 230MB의 RGBA 메모리를 소모합니다. 100장을 한꺼번에 풀면 20GB가 넘어 브라우저 탭이 즉시 강제 종료됩니다.  
**Burst2Gif는 다음의 4가지 절대 원칙을 통해 1,000장을 넣어도 브라우저가 절대 죽지 않는 안정성을 보장합니다.**

1. **디코딩 동시성 Concurrency = 1 (고정)**
   - CPU 코어 수에 관계없이 항상 **한 번에 딱 1장씩만 순차 디코딩 & 인코딩**하여 피크 메모리를 1프레임 크기로 엄격히 제한합니다.
2. **`createImageBitmap` 얼리 리사이즈 (Early Resize)**
   - 브라우저 네이티브(C++) 디코딩 단계에서 목표 해상도(예: 1280px)로 즉시 다운샘플링하여 원본 크기의 거대한 픽셀 버퍼 생성을 원천 차단합니다.
3. **단일 `OffscreenCanvas` 재사용 & `bitmap.close()` 즉시 메모리 반환**
   - 캔버스를 프레임마다 새로 만들지 않고 단 1개만 비워가며 재사용하며, 프레임 처리 직후 `bitmap.close()`를 호출해 그래픽 메모리(VRAM)를 즉각 회수합니다.
4. **OPFS (Origin Private File System) 스트리밍 출력**
   - 인코딩된 바이너리 청크를 RAM에 계속 쌓지 않고 브라우저의 전용 임시 디스크 파일에 실시간 기록합니다. (OPFS 미지원 브라우저는 256MB 메모리 세이프 가드 fallback 적용)

## 🚀 사용 흐름

```text
사이트 접속
   ↓
사진 선택 또는 Drag & Drop (최대 1,000장)
   ↓
사진 자동 자연수 정렬 (img1, img2, img10)
   ↓
실시간 미리보기 & 타임라인 순서 편집
   ↓
속도 및 크기 선택
  - 보통 화질 : 1280px (기본 추천)
  - 작은 용량 : 960px  (메신저/공유)
  - 고화질   : 1920px (PC 감상)
   ↓
[GIF 만들기] ➔ 1장씩 안정적 스트리밍 인코딩
   ↓
미리보기 확인 및 [다운로드]
```

## 🛡️ 작업량 기반 안전장치 (WorkPixels)

```text
WorkPixels = outputWidth × outputHeight × frameCount
```
- **≤ 250M (일반)**: 안전하게 즉시 생성
- **250M ~ 600M (무거움)**: 정상 생성 (처리 시간 안내)
- **600M ~ 1.2B (매우 무거움)**: 해상도 하향 권장 카드 표시
- **> 1.2B (위험)**: 브라우저 보호를 위해 원클릭 **[1280px로 변경하기]** 버튼 제공

## 💻 로컬 개발 및 빌드

```bash
# 1. 프론트엔드 의존성 설치
cd frontend
npm install

# 2. 로컬 개발 서버 기동
npm run dev

# 3. 무결성 타입 검사
npm test

# 4. 정적 프로덕션 번들 빌드
npm run build
```

빌드된 `frontend/dist` 디렉토리는 별도의 백엔드 없이 **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages** 등 정적 호스팅 서비스 어디에나 그대로 올려 즉시 배포할 수 있습니다.

## 📦 기존 백엔드(Python + FFmpeg) 버전 안내

기존의 Python/FastAPI + FFmpeg 2-Pass 백엔드 기반 코드는 **[`archive/backend-version`](https://github.com/lyw1217/burst2gif/tree/archive/backend-version)** 브랜치에 안전하게 보존되어 있습니다. 필요 시 언제든지 해당 브랜치로 전환하여 로컬 배치 스크립트(`run.bat`, `run.sh`)를 이용하실 수 있습니다.
