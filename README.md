# Burst2Gif (연사 사진 GIF / MP4 변환기)

장당 약 20MB에 달하는 고용량 연사 사진들을 로컬 환경에서 부드럽고 가볍게 불러와 순서를 편집하고, 속도(FPS)와 해상도(1080p, 720p 등)를 정밀하게 제어하여 고화질 GIF 및 MP4로 변환해주는 웹 서비스입니다.

---

## 🌟 주요 특징

1. **로컬 고속 인코딩 (FFmpeg 풀 파이프라인 연동)**
   - **고화질 GIF**: `palettegen` (2-Pass 차이 기반 팔레트 추출) + `paletteuse` (디더링) 필터를 적용하여 색상 왜곡과 용량 뻥튀기 없는 최적의 고품질 GIF 생성.
   - **모바일/웹 호환 MP4**: H.264 (`libx264`) 및 `yuv420p` 픽셀 포맷으로 스마트폰, SNS 어디서든 즉시 재생 가능.
2. **듀얼 로드 지원 (초고속 폴더 스캔 & 드래그 앤 드롭)**
   - **로컬 폴더 경로 입력**: 수백 MB ~ 수 GB의 사진도 서버 업로드 대기 없이 디스크에서 0초 만에 로드.
   - **드래그 앤 드롭**: 브라우저 화면에 사진들을 직접 끌어다 놓아 간편 업로드.
3. **20MB 고용량 대응 온디맨드 썸네일 캐시**
   - 브라우저의 탭 튕김(OOM)을 방지하기 위해 백엔드에서 500px급 초경량 WebP 썸네일을 자동 캐싱하여 서빙.
4. **타임라인 순서 편집 및 개별 컷 제어**
   - 썸네일 카드를 마우스로 드래그하여 순서 재배치 가능.
   - 불필요하거나 흔들린 컷 1클릭 개별 삭제.
   - 파일명 기준 오름차순 자연수 정렬 및 역순 정렬 원클릭 지원.
5. **실시간 프리뷰 (미리보기)**
   - 변환 전 브라우저 Canvas에서 지정한 FPS 속도 그대로 실시간 슬라이드쇼 재생/일시정지/프레임 탐색.
6. **로컬 탐색기 원클릭 연동**
   - 변환 완료 시 브라우저 직접 다운로드 및 윈도우 탐색기에서 결과 파일 위치 바로 열기 지원.

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (가장 간편)
프로젝트 루트의 **`run.bat`** 파일을 더블 클릭하면 서버가 구동되고 자동으로 브라우저(`http://localhost:8000`)가 열립니다.

### 방법 2. 수동 실행 (터미널)
```bash
# 백엔드 실행
cd backend
.\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```
브라우저에서 `http://localhost:8000`으로 접속합니다.
